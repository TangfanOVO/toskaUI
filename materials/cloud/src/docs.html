    减弱动态
              
            
    
          
    
          
    这里调的会同时用在整个站上的预览；“复制代码”会把调好的这组手感和上面选的弹层样子一起带走。“减弱动态”是看看系统开了减弱动态效果时，组件长什么样。
    
        
    
      
    

      
    
        
    怎么用
    
        
    
          
    复制代码
    拿到的是一个完整的 HTML 文件，存成 .html 用浏览器打开就能跑。颜色在 :root 的几个变量里，手感在脚本里的 F。
    
          
    复制 Prompt
    一段说明，写清楚这个材质的规则和这个组件怎么动。交给 AI，用你项目里自己的框架重做一遍。
    
          
    换配色
    只换 --bg、--ink、--body 这几个颜色，组件、烟和压在实心上的字都会跟着变。
